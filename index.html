Access History

Support & FAQ

Setup

How do I install it? Install from the Atlassian Marketplace listing like any other Jira app. No configuration is required — it starts working immediately.

Where do I find it after installing? Jira Settings (gear icon) → Apps → Access History in the left sidebar. If you don't see it there, confirm you're logged in as a Jira administrator on that specific site — the page requires site admin permission to view.

When does the first snapshot happen? Automatically, within a few minutes of install, and then every week after that. You can also click Run snapshot now on the app's page at any time — for example, right before an audit — instead of waiting for the weekly schedule.

Using it

What am I looking at in the table? Each row is one project, one role, one member: who has that role on that project, as of the snapshot's timestamp.

Why are some rows missing / hidden? By default, app and integration accounts (Slack for Jira, Automation for Jira, this app itself, etc.) are hidden from the table so you're looking at human access, not integrations. Toggle "Hide app and integration accounts" off to see everything.

How are app accounts detected? Membership in Jira's own atlassian-addons-project-access role, which Jira reserves specifically for app/integration access — a reliable, built-in signal, not a guess.

A role shows "(no members)" — is that a bug? No. It means that role exists on the project but currently has nobody assigned to it. This is normal for roles like "Viewer" that a project simply never uses.

Does the CSV export match what's on screen? The CSV always includes every row — including app accounts, clearly labeled — regardless of whether the on-screen toggle is hiding them. The toggle only affects the table view, so the exported record for an audit is always complete.

How far back does history go? Roughly two years (104 weekly snapshots) are kept per site. Older snapshots are automatically removed to keep storage size bounded.

Data & privacy

See the Privacy Policy for the full policy. Short version: everything runs inside Atlassian's own infrastructure, nothing is sent to a third party, and only site admins can see the data.

What happens if I uninstall the app? Stored snapshots become inaccessible immediately and are permanently deleted within 28 days.

Pricing
